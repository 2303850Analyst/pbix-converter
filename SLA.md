# SLA формирования пользовательского DOCX

## Исключение служебных таблиц

В пользовательский DOCX не включаются таблицы, имя которых начинается с одного из следующих шаблонов:

| Шаблон имени таблицы |
|---|
| `Local*` |
| `DateTableTemplate*` |
| `H$*` |
| `R$*` |
| `U$*` |

Сравнение выполняется без учёта регистра.

## Методика вывода примеров значений

Примеры формируются только для колонок встроенной локальной модели. Строки таблиц целиком не сохраняются и в DOCX не переносятся.

Проверки выполняются последовательно:

| Классификация | Условие | Результат в DOCX |
|---|---|---|
| Служебное или скрытое поле | Скрыта таблица или колонка либо название похоже на ID, login, UPN, e-mail, телефон, GUID, token, password и аналогичный идентификатор | Примеры не читаются |
| Высокая или неизвестная кардинальность | Более 200 уникальных значений либо количество неизвестно | `Нет примеров: >200 значений или число неизвестно` |
| Дата или время | Тип содержит `date` или `time` | `Дата; примеры не выводятся` |
| Числовое поле | Числовой или другой неприменимый тип | `Числовое поле; примеры не выводятся` |
| Категориальный текст или Boolean | Не более 200 уникальных значений | До пяти наиболее частых значений |
| Нет подходящих значений | После удаления пустых и запрещённых значений ничего не осталось | `Нет значений` |
| Ошибка чтения | Профилирование колонки завершилось ошибкой | `Не удалось получить` |
| Профилирование отключено | Указан `--no-examples`, лимит равен нулю или модель недоступна | `Не проверялось` |

Дополнительные правила:

- по умолчанию выводится максимум пять примеров;
- допустимый лимит запуска — от 0 до 5;
- значения сортируются по частоте;
- количество повторений в DOCX не выводится;
- каждое значение ограничивается 80 символами;
- пустые значения исключаются;
- значения, похожие на e-mail, исключаются;
- данные читаются блоками, но исходные блоки и строки не сохраняются;
- значения фильтров извлекаются отдельно из metadata условия фильтра;
- для одного фильтра допускается до 20 уникальных сохранённых значений;
- `true`, `false` и `null` отображаются как `Да`, `Нет` и `Пусто`.
