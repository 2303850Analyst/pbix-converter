PBIX Converter: офлайн-запуск в VDI

1. Полностью распакуйте ZIP в локальную папку.
2. Запустите start_pbix_doc.cmd двойным щелчком.
3. При первом запуске рядом будет создана локальная папка .venv.
4. Зависимости устанавливаются только из вложенной папки wheelhouse; интернет не используется.
5. Следующие запуски выполняются тем же файлом start_pbix_doc.cmd без повторной установки.

Пакет предназначен только для CPython 3.12 x64 в Windows.
