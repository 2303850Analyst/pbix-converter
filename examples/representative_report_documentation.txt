10. RLS и OLS
----------------------------------------------------------------------------------------------------
Обнаруженная схема безопасности:
+-------------------------------+-----------------------------+
| Параметр                      | Значение                    |
+-------------------------------+-----------------------------+
| Статус анализа                | FORMAL_PLACEHOLDER          |
| Тип RLS                       | DYNAMIC_TABLE_MAPPING       |
| Таблица доступа               | UserAccess                  |
| Колонки идентификации         | UserLogin                   |
| Колонки области доступа       | GeographyKey; AccessProfile |
| Функция текущего пользователя | USERPRINCIPALNAME()         |
| Значения логинов              | <IDENTIFIERS NOT SHOWN>     |
+-------------------------------+-----------------------------+
Интерпретация RLS/OLS является формальной заглушкой до первого прогона на боевом PBIX.
Распространение RLS по модели:
+------------------------------------------------------+----------+-----------------------------+
| Путь                                                 | Статус   | Направление security filter |
+------------------------------------------------------+----------+-----------------------------+
| UserAccess[GeographyKey] -> Geography[GeographyKey]… | DETECTED | BOTH then SINGLE            |
+------------------------------------------------------+----------+-----------------------------+
RLS — определения строковой безопасности, найденные в локальной модели:
+-------------------------+------------+---------------------------------------------+-----------+---------------------+
| Роль                    | Таблица    | DAX-фильтр                                  | Состояние | Metadata permission |
+-------------------------+------------+---------------------------------------------+-----------+---------------------+
| Dynamic Regional Access | UserAccess | UserAccess[UserLogin] = USERPRINCIPALNAME() | ENABLED   | READ                |
+-------------------------+------------+---------------------------------------------+-----------+---------------------+
OLS — ограничения доступа к объектам модели:
+-------------------------+---------+---------+------------+------------+
| Роль                    | Область | Таблица | Колонка    | Разрешение |
+-------------------------+---------+---------+------------+------------+
| Dynamic Regional Access | COLUMN  | Sales   | CostAmount | NONE       |
+-------------------------+---------+---------+------------+------------+
Логины в UserAccess не выводятся. Их наличие и кардинальность документируются без значений.
Назначения пользователей или групп общей роли в Power BI Service локально не подтверждены.
